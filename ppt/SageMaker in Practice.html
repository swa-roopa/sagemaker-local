Day 3 · S4 · SageMaker lifecycle and cleanup

Cost cleanup · mandatory

Nobody leaves with an endpoint running

Cloud resources keep billing until you delete them, even when nobody is using them. Like leaving the tap running.

Done means: “your endpoint still present: no”

  • Screenshot: empty Endpoints list
  • No notebook or Studio apps running
  • No pipelines executing
  • No training jobs InProgress
